# WinHide

Herramienta para Windows 10 y Windows 11 que oculta ventanas de la pantalla, de la barra de tareas y de Alt+Tab.

## Qué hace

- Lista ventanas visibles y ventanas ocultas con título de ventana, proceso y PID.
- Oculta la ventana seleccionada de la pantalla, la barra de tareas y Alt+Tab (también con doble clic).
- Restaura la ventana seleccionada cuando quieras volver a mostrarla.
- Mantiene las ventanas ocultas al cerrar WinHide y las detecta al volver a abrirlo.
- Interfaz oscura con bordes, botones redondeados y contador de ventanas visibles y ocultas.
